# «Ոչ ոք չի կարող քեզ խաբել» — 2D կարճամետրաժ

**[Ներբեռնել տեսանյութը (MP4)](out/truth-unmasked-hy.mp4)** · [Հայերեն ենթագրեր (SRT)](out/captions-hy.srt)

Հայերեն, 16:9 կոդով նկարված կինեմատոգրաֆիկ 2D պատմություն՝ հիմնված օգտատիրոջ սցենարի վրա։ 13 հաջորդական կադր, գիշերային/մթնշաղային գունապնակ, նույնականացված գունավոր կերպարներ, խորքային միջավայրեր, լուսային շեշտեր, դինամիկ վերնագրեր, անցումներ, հայերեն էկրանային տեքստ և օրիգինալ սինթեզված երաժշտություն։

## Արդյունքներ

- `out/ոչ-ոք-չի-կարող-քեզ-խաբել.mp4` — 1280×720, 16:9, 30 fps, մոտ 67 վրկ, երաժշտությամբ։
- `out/captions-hy.srt` — հայերեն ենթագրեր։
- `story/shots.json` — կադրային պլան և էկրանային տեքստ։
- `render.py` — կադր առ կադր Pillow նկարչություն և ffmpeg արտածում։

## Նշում ձայնի մասին

Ձայնային նարացիայի ֆայլ չէր կցվել, ուստի այս տարբերակը **խոսքային ձայնագրություն չունի**․ պատմությունը կարճացված է հայերեն էկրանային տեքստերի մեջ։ Միքսում ներառված է միայն բնօրինակ, կոդով սինթեզված մթնոլորտային երաժշտությունը։ Լրիվ սցենարի ձայնագրությունը կարելի է հետագայում համաժամեցնել նույն կադրային պլանի հետ։

## Վերարտադրում

Python 3, Pillow և ffmpeg-ի static binary։ Այս workspace-ում ffmpeg-ը ներբեռնվել է npm-ի `@ffmpeg-installer/linux-x64` փաթեթից (`.cache/video-tools/`)։

```bash
python3 -m pip install pillow --break-system-packages
npm install --prefix .cache/video-tools @ffmpeg-installer/linux-x64 --no-audit --no-fund
python3 projects/truth-unmasked/render.py
```

Պլագինի ուսումնասիրված ուղեցույցները՝ `skills/make-2d-video/references/{style-bible,director-pass,story-breakdown,render-qc}.md`։ Այստեղ օգտագործված է պլագինի նկարագրած մութ 2.5D բեմադրության, rim-light-ի, կադրային ռիթմի, կինետիկ տեքստի և նախատեսված անցումների մոտեցումը։
